## About the Project

**Bidai** is a wedding and household package website designed to make wedding preparation more organized for Pakistani families. It brings package information, furniture, kitchen essentials, selected home appliances, catering, and wedding-related services together in one browsing experience.

Visitors can explore package tiers, compare their listed inclusions, review service information, and submit an inquiry so the Bidai team can discuss requirements and confirm details.

> **Project tagline:** Har Zaroorat, Ek Bidai Package Mein.

## Features

- **Wedding package catalogue** — six package tiers with displayed prices and package descriptions.
- **Package comparison** — a side-by-side comparison table to review listed features.
- **Household categories** — furniture, kitchen essentials, electronics, and catering.
- **Wedding service information** — showroom preview, wedding hall, bridal makeup, photography, videography, and catering sections.
- **Inquiry form** — customer information, wedding details, package selection, and additional requirements.
- **Customer contact options** — WhatsApp and contact details for package inquiries.
- **FAQ and process guidance** — information about how Bidai works and common customer questions.
- **Responsive presentation** — organized content sections and package cards for browsing.

## Running Locally

If the project is configured as a Vite application:

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Move into the project directory:

   ```bash
   cd Bidai
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

Check `package.json` for the actual scripts and dependencies before running these commands.

## Important Information

- Package prices and listed inclusions are based on the website content and may change.
- Confirm final package specifications, registration charges, availability, and location with Bidai before placing an order.
- An inquiry should not be described as a confirmed order unless the application implements that workflow.
- Verify the business's phone number, WhatsApp number, and email before publishing.
- Do not publish API keys, passwords, `.env` files, or private customer information in the repository.
